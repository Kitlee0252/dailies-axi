DAILIES AXI / ARCHITECTURE

dailies-axi 整体架构

一条闭环：agent 交出一版 → 审片人在画面上精确地钉意见 → 剪辑引擎按原素材帧换算并改片 → 客观验收通过才送审 → 每轮锁定留档，偏好按规则沉淀。三块各司其职，只通过带版本号的 JSON 文件交接。

已实现 开发中 未实现 外部工具（复用组件）

三块各自的唯一职责

① dailies-axi · 审 已实现

把审片人的意图变成精确、锁定、可追溯的意见批次。审片页支持播放头拖动、时间段吸附切点、转写叠加和字幕校正，校正在 poll 时写回源转写。读取已经验收的 changes.json，在下一轮显示结果与披露，并采集审片人反应。

② dailies-cut · 改 已实现

管理剪辑表、帧换算、吸附和顺移，生成改动清单，独立渲染验收。analyze 用彩色画面差分和静音找切点并按代理哈希缓存。learn 根据同一账本、参数和计算时间得出相同状态。

skill · 判断 已实现

dailies-axi skill 教流程；dailies-edit 是薄 skill，只写意见分类、授权范围和备选取舍，细节在 references/（维度词表、默认值）。agent 负责理解意见，命令负责算对。

两个 CLI 的命令

CLI命令作用
dailies-axiopen一条命令：建工作区 → ingest → 转写 → build → review → poll；传入合成页则继续下一轮（--note、--outcomes），首次可带 --brief-file
dailies-axiinit · ingest · transcribe · build · review · poll分步版本：建目录、导入素材、重做转写或导入字幕、冻结版本、托管审片页、锁定意见
dailies-axiframe · doctor按 notes 里的帧抽取证据图；检查 Node、FFmpeg、lavish-axi、whisper
dailies-cutanalyze · plan · apply · verify · select分析素材 → 意见变操作草稿 → 暂存候选 → 验收 → 装入工作剪辑表
dailies-cutlearn ingest · plan · status · forget · pause · propose收入意见与反应、给出本轮偏好计划、查看档案、撤销、暂停、生成通用规则提案

一轮的完整路径

#谁做什么
1agentdailies-axi open 粗剪.mp4（或合成页）→ 得到审片链接
2你在审片页上框画面、拖播放头、拖时间段、点字幕、校正字幕、写整片意见 → 发送（有笔记或字幕校正即可发送）
3dailies-axipoll 锁定 v1 的 notes.json，保存校正后的转写，交给 agent
4agent + dailies-cut按 dailies-edit skill：learn ingest → 分类（learn.classify.json）→ learn plan → plan 生成剪辑草稿 → apply 暂存候选（口味类给多个备选）→ verify
5dailies-axidailies-cut select 安装通过验收的候选；dailies-axi open source/index.html --outcomes …/changes.json 建 v2，展示结果、跳转和偏好披露，并回帖到上一轮会话
6你在 v2 里认可、拒绝、选备选或重开上一轮结果，并继续提新意见；回到第 2 步
7learn下一轮 learn ingest 收入你的选择与反应，更新项目决定和审片人档案；终稿签收时 learn ingest --signoff，learn propose 把达标的通用规则交人工批准
