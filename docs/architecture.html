DAILIES AXI / ARCHITECTURE

dailies-axi 整体架构

一条闭环：agent 交出一版 → 审片人在画面上精确地钉意见 → 剪辑引擎按原素材帧换算并改片 → 客观验收通过才送审 → 每轮锁定留档，偏好按规则沉淀。三块各司其职，只通过带版本号的 JSON 文件交接。

已实现 开发中 未实现 外部工具（复用组件）

三块各自的唯一职责

① dailies-axi · 审 已实现

把审片人的意图变成精确、锁定、可追溯的意见批次。读取已经验收的 changes.json，在下一轮显示结果与披露，并采集审片人反应。

② dailies-cut · 改 已实现

管理剪辑表、帧换算、吸附和顺移，生成改动清单，独立渲染验收。learn 根据同一账本、参数和计算时间得出相同状态。

skill · 判断 已实现

dailies-axi skill 教流程；dailies-edit skill 只写行家的判断规则。agent 负责理解意见，命令负责算对。
