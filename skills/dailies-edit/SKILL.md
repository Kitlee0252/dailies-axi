# Dailies Edit

Read `brief.md` and `brief.json` when present before interpreting notes. If the brief was never offered, ask once about the audience, publication channel, intended length and goal. Respect a skipped brief. Keep source media, proxies, evidence, renders, feedback, and candidates inside the private review workspace. Never share or export them through Lavish.

1. **Read locked feedback.** Run `dailies-cut learn ingest --round vN`. Classify the pending notes using [the dimensions and rules](references/dimensions.md). Run `learn ingest --round vN --classified FILE` and `learn plan --round vN` before drafting. Read the project decisions and state changes. Run `dailies-cut plan vN` against locked feedback. Read the reviewer's exact words, look at the evidence frames, and listen around the boundaries. A click shows where the reviewer noticed the problem. Use the waveform and picture to judge what the note refers to.
2. **Classify and record each note.** Fill the draft's `ops` with the note ID, intent, authority, and scope. Carry out explicit cuts, trims, and overlays. Treat ambiguous direction, pacing, and style as taste. Use the learning plan to choose the main treatment and prepare named candidates with the same explicit changes. A candidate preference is one option. An active preference supplies the main treatment and two variants. An unresolved conflict supplies one per direction. Use three options when the plan has no prior preference. Hand the reviewer the private comparison and let them choose. If the ambiguity changes the message, an earlier approval, or permission to edit, use `ask` with the concrete choice. Use `decline` with a reason for unsupported work.
   Move existing footage when the requested order is clear. Insert an unused ingested shot at the authorized destination. For a different take, audition the plan’s replacement candidates and check that the line and cut points match. Adjust gain or fades on the affected words or clip and mute only where the sound should disappear. Use a static punch-in when it adds emphasis or helps cover a tighten jump cut. Check the crop for lost details.
3. **Respect the authorized scope.** Explain an authorized global treatment and state how many places it affected. Flag similar problems outside that scope as suggestions. Preserve previous decisions. Copy the learning plan basis into the operation and its disclosure into the matching outcome. Offer an unrelated preference once without editing, unless the reviewer opted in to automatic application. If a cut and a caption conflict, show the lost anchor and ask which to keep. For continuous talking-head footage, weigh a preserved breath against the visual jump when offering pacing alternatives.
4. **Check the actual output.** Provide checked expected dialogue for an audible full render. Run `dailies-cut apply` and `dailies-cut verify` for each candidate. Above three minutes, ask whether to render the full film. If the reviewer declines, use the cut-window verification and report its coverage. Review the splice images and listen to the audio. Correct objective failures before sending a candidate for review. After three unsuccessful attempts, report the precise failure and leave the affected note open.
5. **Deliver the selected version.** Run `dailies-cut select`, then open the working composition with the selected candidate's verified `changes.json` as outcomes. Use the reviewer's language, say what changed, and give the clickable frame or range when there is one. Say what still needs their decision. Include learning state changes, inferred reopenings, and the context of stated preferences in the outcome. On a one-sentence revocation, use `dailies-cut learn forget KEY --quote TEXT` and confirm it. On explicit final signoff, run `learn ingest --signoff`, then `learn propose` and report new proposal IDs for human approval.

Use the CLI for coordinates, snapping, ripple, rendering and verification. See `dailies-cut --help` and the Dailies AXI README for the file contracts.
